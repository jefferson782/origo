# Origo

Sistema de escala de voluntários para igrejas: departamentos, cultos, escalas e avisos, com autenticação e banco de dados via Supabase.

## Desenvolvimento

Requer Node.js e npm.

```sh
npm i
npm run dev
```

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run lint` — checagem de lint
- `npm test` — testes
